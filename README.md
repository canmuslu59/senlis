# SENLIS

SENLIS is a native Android fragrance-discovery application.

## Current v0.3.0
- Native Android UI; no screenshot-backed screens
- Discover home
- 4-step scent analysis
- Recommendation scoring
- Perfume search
- Missing-catalog local queue
- Favorites with local persistence
- Perfume detail pages
- Similar-scent flow
- Persistent scent profile
- Dark brown / champagne-gold SENLIS design system

Package: `com.innative.senlis`

The initial catalogue is local and intentionally replaceable by the planned production catalogue/backend.
