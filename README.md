# SENLIS

SENLIS, kişisel koku zevklerini analiz ederek kullanıcıya uygun parfümleri keşfetmeyi amaçlayan Android uygulamasıdır.

## İlk sürüm
- Lüks koyu / şampanya-altın arayüz
- 4 adımlı koku keşif akışı
- Nota, kullanım amacı ve bütçe filtreleri
- Kişisel eşleşme skoru
- Sonuç ve parfüm detay ekranı

## Yol haritası
- Ücretsiz sunucu/veritabanı altyapısı
- Geniş parfüm kataloğu
- 2–3 kaynaklı veri doğrulama
- Ödüllü reklam ile ek öneriler
- Kullanıcı favorileri ve koku profili
